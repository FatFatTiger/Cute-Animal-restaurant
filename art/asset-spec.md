## 1. 资产生产清单（按 base-parts atlas 槽位）

**原则**：单一白模 atlas ≤1024²（art-bible §4.4.1 / §A.1）。下表逐项列出 头6 / 身5 / 耳8 / 尾6 / 肢3 + 面部 + 配件8 + 12 配色 + 6 表情，标注：**尺寸建议 / 是否进主包 atlas / LOD 层级**。

**LOD 定义**（程序化拼装同源，LOD 为渲染分辨率与图层策略，非独立贴图）：
- **LOD0** — 店内/抽卡/互动：100% atlas 分辨率，Spine 骨骼 + VFX + 面部动画。
- **LOD1** — 卡牌立绘：100% 分辨率静态合成，表情烘焙，无骨骼。
- **LOD2** — 图鉴缩略/UI 头像：50% 降采样，可省略配件层，启用 mipmap。

**"是否进主包 atlas"**：`atlas_guide`（主包）= 新手 5 只 N 动物 + 1–2 只 mascot 所需的槽位子集；`atlas_full`（分包）= 全量槽位。水族专属槽位（H5/E7/T5）仅长线大版本出现，**一律进分包**。引导子集随新手脚本最终确认（协调 文策渊）。

## 2. Atlas 打包规格

### 2.1 主包 atlas（引导最小集）vs 分包 atlas（全量）
| atlas | 落点 | 槽位范围 | 尺寸上限 | 体积预算 | 加载时机 |
|---|---|---|---|---|---|
| `atlas_guide` | **主包** | 引导子集（H0/H1/H3/H4、B0/B2/B3、E0/E5/E6、T0/T3/T4、L0/L2、全部面部、A0/A1）+ 水族外全家族基础槽（首发 36 渲染所需子集） | ≤1024² | 0.8–1.2 MB | 首屏即载 |
| `atlas_full` | **分包** | 全量槽位（含 H2/E1–E4/T1/T2/L1/A2–A7）+ 水族专属（H5/E7/T5） | ≤1024² | ≤1.0 MB（压缩后） | 进图鉴/餐厅/抽卡结果时 |

> **切分规则**：`atlas_guide` 是 `atlas_full` 的**严格子集**，二者共享同一套槽位 UV 坐标约定（见 2.4）。首发 36 只 = 哺乳19/鸟10/圆团7，**不含水族**，故 `atlas_guide` 已覆盖首屏教学动物；水族专属 3 槽（H5/E7/T5）仅在长线大版本分包加载。教学 mascot 的精确槽位组合最终与新手脚本（文策渊）对齐。

### 2.2 纹理格式（机型回退链）
| 平台/机型 | 首选格式 | 回退格式 | 备注 |
|---|---|---|---|
| iOS（A8+，支持 ASTC） | **ASTC 6×6**（或 8×8 省体积） | PVRTC 4bpp | Cocos 自动选 ASTC；老机型 PVRTC |
| Android（GLES 3.0+） | **ASTC 6×6** | ETC2_RGBA (RGBA8) | 主流中高机型 |
| Android（GLES 2.0 老机） | **ETC2_RGBA** | 源 PNG-8 / WebP 兜底 | 低色域设备见 §3.3 |
| 编辑器/兜底主源 | PNG-8 / WebP（无损母版） | — | 烘焙母版，构建期转目标格式 |

> 压缩目标：白模为扁平+轻软阴影、alpha 边界少，ASTC 6×6 / ETC2_RGBA 视觉损失可控（R3 待真机证伪）。

### 2.3 单图 padding 与边界处理
- 每个切片 **2px 透明 padding + 1px 边缘 extrude（外扩描边色）**，防 tint/缩放时邻切片渗色与描边断裂。
- 描边为统一暖棕 `#8A7268`（art-bible §4.1），extrude 取描边色而非透明，避免呼吸/微摆动画露白边。
- premultiplied alpha 开启，混合边缘干净。

### 2.4 合图策略
- 打包算法：**Max-Rects**（skyline 备选），power-of-two 画布（1024²）。
- **坐标约定共享**：`atlas_guide` 与 `atlas_full` 对共享槽位使用同一 UV 矩形坐标，运行期装配代码仅持一份坐标表；`atlas_full` 仅在末尾追加专属/扩展槽位。
- **mipmap**：生成 mip 链支撑 LOD2 降采样；首屏引导可关 mip 省主包，分包开启。
- **单只零增长**：新增动物 = 仅写参数（~11–64B JSON，art-bible §4.4.2），atlas 字节 delta=0（V1 已实跑通过）。

## 3. 着色器 tint 规格（分层上色）

> 锁定（ADR-4）：身份色（角色填充）与稀有度色（UI 卡框）**分属不同 UI 层**，独立渲染、互不覆盖。

### 3.1 身份色层（12 配色 → 顶点色/角色填充层）
| 项 | 规格 |
|---|---|
| 作用对象 | 角色模型层（Spine/2D 拼装的白模切片） |
| 上色通道 | 3 通道：`fill`（主填充）／`shade`（轻软阴影，fill 降明 ~12–15%）／`outline`（统一暖棕 `#8A7268`） |
| 数据来源 | `COLOR_PRESETS` 12 套（§1.8），经顶点色或材质 tint 注入 |
| 混合模式 | 普通 alpha blend，叠于场景/卡面底 |
| 家族约束 | 每家族绑定 4 套预设，跨家族不串味；SSR 仅可叠加高光部件/特效光环，**不改剪影家族**（art-bible §4.4.3.5） |

### 3.2 稀有度色层（4 档卡框 UI 层）
| 稀有度 | 主色 HEX | 角标形状（色盲安全） | 层内混合 | 演出 |
|---|---|---|---|---|
| N | `#A8C0B0` 灰绿 | 圆点 | 卡框条 multiply | 无 |
| R | `#8FB8E0` 蓝 | 单钻 | 卡框条 multiply + 轻光 screen | 轻光 |
| SR | `#C9A6E8` 紫 | 双钻 | multiply + 边框微光 screen | 边框微光 |
| SSR | `#F4C95D` 金 | 星冠 | multiply + 流光 screen | 流光 + 粒子 + 全屏彩带 |

> 稀有度色**只作用于 UI 卡框层**（顶部色条占卡高 6–8% + 角标 + 纹理），绝不进入角色身份色层；蓝身份鸟 + 蓝 R 条时以**角标形状**区分（art-bible §7.2 护栏）。

### 3.3 低色域 / 老旧设备 fallback（R3 待证伪）
- 若设备不支持自定义 shader tint 或色域受限：
  1. **形状双编码兜底**（首选）：稀有度仅依赖角标形状（圆点/单钻/双钻/星冠）即可辨识，不依赖 tint 还原——保证可读（对齐 §9 色盲安全）。
  2. **简化调色板**：身份色回退至 4 族基础 fill（不追求 12 套精细渐变），降低 shader 负担。
  3. **预烘焙变体（次选，避免）**：逐家族×配色预烘焙 tinted 白模会膨胀 atlas，仅在 shader 完全不可用时启用，且需复核 4MB/分包体积（资产风险 AR-2）。
- 低色域设备统一采用 art-bible §3.2「同套色相降明度版本」逻辑，由 shader 参数化降明，不新增贴图。

## 5. 字体与 UI 资产

### 5.1 字号阶梯（基准 750×1334，art-bible §6）

|---|---|---|

| H2 | 30–32px | 区块标题 |
| Body | 22–24px | 正文 |

| Num | 24–28px | 数字/计数（暖橘需描边兜底） |

> 字重常规/中粗两档，禁极细(<300)与极粗(>800)；字色暖墨 `#5A4A42` 为主（置奶白 8:1，WCAG AAA）。

### 5.2 圆润字体需求
| 用途 | 字体 | 落点 | 体积 |

| 标题/品牌 | 站酷快乐体 / 得意黑圆体 | 主包子集 + 分包全量 | 子集 0.1–0.2 MB |

| 兜底 | 系统圆体（无自定义时） | 运行时回退 | 0 |

> 主包仅裁剪教程/首屏用字子集（≤0.2MB）；完整字体随 UI 分包或系统回退（tech-prototype §4 行 5）。

### 5.3 图标集（含稀有度色盲安全形状）
