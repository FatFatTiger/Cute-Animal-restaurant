**LOD 定义**（程序化拼装同源，LOD 为绘制分辨率与图层策略，非独立贴图）：
- **LOD0** — 店内/抽卡/互动：100% 绘制分辨率，canvas2d 参数化绘制 + 正弦 idle 动效 + VFX + 面部动画（无骨骼）。

- **LOD2** — 图鉴缩略/UI 头像：50% 绘制缩放，可省略配件层；mipmap 不适用（矢量分辨率无关，任意 DPR 清晰）。

**"是否进主包绘制库"**：主包 = 新手 5 只 N 动物 + 1–2 只 mascot 所需的部件绘制函数与参数子集；分包 = 全量参数。水族专属槽位（H5/E7/T5）仅长线大版本出现，**一律进分包**。引导子集随新手脚本最终确认（协调 文策渊）。

## 2. 程序化部件绘制库组织（零贴图，atlas 零增长）

> **修订：2026-07-29 正式 pivot 离 Cocos，以微信原生 canvas2d 程序化零贴图为准（用户 OP1-A）**：原「Atlas 打包规格（PNG/WebP + ASTC/ETC2 + Max-Rects 合图 + mipmap）」整体不适用，已重写为「canvas2d 程序化绘制库组织」。atlas 字节=0（不变量#1）。

### 2.1 主包绘制库（引导最小集）vs 分包参数（全量）
| 项 | 落点 | 内容范围 | 体积预算 | 加载时机 |
|---|---|---|---|---|
| **主包绘制库** | **主包** | 部件绘制函数（canvas2d 矢量原语）+ 引导参数子集（H0/H1/H3/H4、B0/B2/B3、E0/E5/E6、T0/T3/T4、L0/L2、全部面部、A0/A1）+ 水族外全家族基础槽（首发 36 渲染所需子集） | 含于核心框架 JS（atlas 字节=0） | 首屏即载 |
| **分包参数** | **分包** | 全量参数（含 H2/E1–E4/T1/T2/L1/A2–A7）+ 水族专属（H5/E7/T5） | 极小（≈KB 级/只） | 进图鉴/餐厅/抽卡结果时 |

> **切分规则**：主包绘制库是分包参数的**严格子集**（共享同一套绘制函数与参数表）；首发 36 只 = 哺乳19/鸟10/圆团7，**不含水族**，故主包已覆盖首屏教学动物；水族专属 3 槽（H5/E7/T5）仅在长线大版本分包加载。教学 mascot 的精确参数组合最终与新手脚本（文策渊）对齐。

### 2.2 纹理格式（已删除 · 零贴图范式下不适用）
- **原 ASTC / PVRTC / ETC2 / PNG-8 / WebP 回退链整体删除**：零贴图范式下不存在位图纹理格式（不变量#1）。所有视觉由 canvas2d 图元（roundRect / circle / ellipse / text，clear/rect 为底；R5 契约仅支持此六类 op，无 path/arc 等）+ JS 运行时 `fillStyle`/`strokeStyle` 运行时绘制，无纹理压缩、无机型回退链。
- 视觉保真由矢量绘制参数（描边权重、阴影方向、渐变）保证，与机型无关（R3 原风险随之消解）。

### 2.3 描边与边界处理（矢量等效）
- 每个部件以 **1–2px 统一暖棕 `#8A7268` 描边**（art-bible §4.1）闭合轮廓，**抗锯齿由 canvas2d 原生提供**，无需位图 padding/extrude。
- 描边取同描边色（非透明），避免呼吸/微摆动画露白边（等价于原 extrude 目的）。
- 半透明混合由 `ctx.globalAlpha` 控制，边缘干净。

### 2.4 绘制库组织与坐标约定
- **绘制函数 + 参数表**：所有部件由一组 canvas2d 绘制函数实现；共享同一套参数键（partsId / colorPreset / expression / 形变），运行期装配代码仅持一份参数表。
- **坐标约定共享**：主包与分包对共享部件使用同一参数键与绘制函数，分包仅在参数表末尾追加专属/扩展部件。
- **单只零增长**：新增动物 = 仅写参数（~11–64B JSON，art-bible §4.4.2），atlas 字节 delta=0（V1 已实跑通过；零贴图下恒成立，不变量#1）。

## 3. 参数化填色规格（分层上色，JS 运行时填色）

> 锁定：身份色（角色填充）与稀有度色（UI 卡框）**分属不同 UI 层**，独立渲染、互不覆盖（分层同 art-bible §4.2）。

### 3.1 身份色层（12 配色 → canvas2d 角色填充层）
| 项 | 规格 |
|---|---|
| 作用对象 | 角色绘制层（canvas2d 程序化部件绘制，无白模切片） |
| 上色通道 | 3 通道：`fill`（主填充，`ctx.fillStyle`）／`shade`（轻软阴影，fill 降明 ~12–15%）／`outline`（统一暖棕 `#8A7268`，`ctx.strokeStyle`） |
| 数据来源 | `COLOR_PRESETS` 12 套（§1.8），经 JS 运行时 `fillStyle`/`strokeStyle` 填色注入 |
| 混合模式 | 普通 alpha（`ctx.globalAlpha`），叠于场景/卡面底 |
| 家族约束 | 每家族绑定 4 套预设，跨家族不串味；SSR 仅可叠加高光部件/特效光环，**不改剪影家族**（art-bible §4.4.3.5） |

### 3.2 稀有度色层（4 档卡框 UI 层）
| 稀有度 | 主色 HEX | 角标形状（色盲安全） | 层内混合（纯 alpha，无 composite） | 演出（角标/纹理编码，非 screen） |
|---|---|---|---|---|
| N | `#A8C0B0` 灰绿 | 圆点 | 卡框条 纯 alpha 叠加（`globalAlpha`） | 无 |
| R | `#8FB8E0` 蓝 | 单钻 | 纯 alpha 叠加 + 角标单钻 | 轻光（角标/纹理编码） |
| SR | `#C9A6E8` 紫 | 双钻 | 纯 alpha 叠加 + 边框微光（角标/纹理） | 边框微光 |
| SSR | `#F4C95D` 金 | 星冠 | 纯 alpha 叠加 + 流光（角标/纹理） | 流光 + 粒子 + 全屏彩带 |

> 稀有度色**只作用于 UI 卡框层**（顶部色条占卡高 6–8% + 角标 + 纹理），绝不进入角色身份色层；蓝身份鸟 + 蓝 R 条时以**角标形状**区分（art-bible §7.2 护栏）。**混色约束（2026-07-30 闭环）**：`applyCommands`（render.js L769-829）**无任何 `globalCompositeOperation` 处理**，`multiply`/`screen` 无法落地，已自 §3.2 删除；稀有度演出一律以「纯 alpha 叠加（`globalAlpha`）+ 角标形状/纹理编码」实现，严守零贴图契约（与 art-bible §7.2 双编码一致）。

### 3.3 低色域 / 老旧设备 fallback（R3 待证伪）
- 若设备色域受限或填色精度不足：
  1. **形状双编码兜底**（首选）：稀有度仅依赖角标形状（圆点/单钻/双钻/星冠）即可辨识，不依赖填色还原——保证可读（对齐 §9 色盲安全）。
  2. **简化调色板**：身份色回退至 4 族基础 fill（不追求 12 套精细渐变），降低绘制负担。
  3. **无位图预烘焙**：零贴图范式下不存在「预烘焙 tinted 白模」膨胀问题（atlas 字节恒=0，不变量#1）；AR-2 原风险随之消解。
- 低色域设备统一采用 art-bible §3.2「同套色相降明度版本」逻辑，由 JS 运行时参数化降明（fillStyle HSL 降明），不新增贴图。
