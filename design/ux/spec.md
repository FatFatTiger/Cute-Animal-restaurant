## 1. 信息架构与导航（IA & Navigation）

### 1.1 全局导航模型（推荐方案）

```
                         ┌──────────────────────────┐
                         │   主菜单 (Hub / 总览浮层)  │
                         │  ☰ 任意模块左上唤出        │
                         └───────────┬──────────────┘
              ┌──────────────┬───────┴───────┬──────────────┐
              ▼              ▼               ▼              ▼
        ┌──────────┐  ┌──────────┐   ┌──────────┐   ┌──────────┐
        │  🏠 餐厅  │  │  🎴 抽卡  │   │  📖 图鉴  │   │  🛍 商店  │
        │ (首页/默认)│  │          │   │          │   │          │
        └──────────┘  └──────────┘   └──────────┘   └──────────┘
              ▲              ▲               ▲              ▲
              └──── 常驻底部 Tab Bar（4 入口，1 次点击切换）────┘

   养成互动（喂食/送礼/上岗/升星）= 非独立 Tab，从「餐厅点动物」或「图鉴点动物」
   → 弹出【动物详情 Modal】（覆盖层），不新增导航层级。
   餐厅内部子视图（店外 / 店内 / 厨房）= 同模块内「场景跳转」（淡入切换），非 Tab。
   抽卡揭示演出 = 全屏 Overlay，非新 Tab。
```

### 1.2 取舍说明：底部 Tab vs 场景跳转栈 vs 侧边抽屉

| 方案 | 取舍结论 | 理由（对齐锁参与红线） |
|---|---|---|
| **底部 Tab Bar（4）** ✅ 采用 | 常驻 餐厅/抽卡/图鉴/商店 | ① 女性向单手拇指可达（主操作区偏下）；② 核心循环 4 入口均为 1 次点击，满足「三屏内核心循环」；③ 放置收菜节奏不被多级返回打断（防认知过载红线）。 |
| 纯场景跳转栈 | 否决 | 回「餐厅」收菜需多次返回，破坏挂机节奏；层级深，违反单局≤5 分钟与低操作红线。 |
| 侧边抽屉做主模块 | 否决 | 单手难及、隐藏过深，违反可达性（Standard 级按钮≥44px、单手可达）。 |
| 主菜单作第 5 个 Tab | 否决 | 主菜单定位为「总览/设置/账号/收集进度/订阅管理」，是 Hub 而非玩法模块；以 ☰ 浮层承载，避免 Tab 过多导致认知过载。 |

**决策**：主菜单 = 首启着陆页 + 任意模块 ☰ 唤出的总览浮层；底部 4 Tab 承载玩法主循环。这是本规格最关键的一条导航决策，请评审确认。

### 1.3 全局持久层（所有屏共用）

- **顶部状态条（HUD）**：`⭐星券 N ｜ 💎钻石 N ｜ 🍖食材 N`（碎片在动物详情内展示）。置顶常驻，任何模块可见，避免「货币焦虑跳转」。
- **左上 ☰**：主菜单浮层。
- **右上 💬**：微信订阅消息入口（见 §6.3）。
- **底部 Tab**：餐厅/抽卡/图鉴/商店（当前屏高亮，暖橘描边+樱粉底）。

## 2. 核心流程（Core Flows）

### 2.1 首次进入引导（≤3 步，零失败）

```
[启动] → [① 收下 5 只 N 动物] ──点击礼物盒──▶ [动物入店, 自动上岗]
   → [② 看它们自己开店营业] ──观察 3–5s 呼吸/接单动画──▶ [产出首笔 ⭐星券 +🍖食材飘字]
   → [③ 领今日免费单抽 + 抽 1 次] ──点击「免费抽」──▶ [揭示 1 只动物(前10抽保底≥1 SR)]
   → [进入主循环]  ◀── 引导结束, 之后完全自由, 无强制步骤 ──▶
```
- 全程 ≤3 个主动点击，无文字硬塞；用角色动画与飘字「示范」而非「教学」。
- 第③步免费单抽计入全局 `pity` 与「新手前 10 抽≥1 SR」保底（对齐 gacha §2）。

### 2.2 日常循环（cook→serve→earn→upgrade，单局 ≤5 分钟）

```
┌─ 登录 ───────────────────────────────────────────────┐
│ [收菜] 领取离线/挂机收益 (⭐星券 +🍖食材, 无丢失, 不惩罚) │
│    │                                                  │
│    ▼                                                  │
│ [巡查] 轻点店内动物/订单状态 (可选, 非强制)            │
│    │                                                  │
│    ▼   (自动进行, 无需操作)                            │
│ [产出] 动物自动 cook→serve → earn(⭐星券+🍖食材) +好感  │
│    │                                                  │
│    ▼                                                  │
│ [升级] 花 ⭐星券升 座位/工位/菜谱 (cook→serve→earn→upgrade 闭环) │
│    │                                                  │
│    ├──▶ [收集] 攒 ⭐/💎 → 抽卡得新动物/装饰           │
│    ├──▶ [养成] 喂食/送礼 → 好感↑ → 上岗加成          │
│    └──▶ [下线] 收益继续累积 (离线公式生效)             │
└──────────────────────────┬───────────────────────────┘
                           ▼  (回登录, 收益已增长)
```
- 「产出」阶段全自动，玩家只需在「收菜/升级/抽卡/养成」节点轻点，完美契合零失败、低操作、慢节奏（concept §2.3 Sensation/Submission）。

### 2.3 抽卡流程（单抽 / 十连 → 揭示 → 重复处理）

```
[抽卡界面] ─选择─▶ 货币(⭐星券/💎钻石) × 单抽(100)/十连(900,9折)
    │
    ▼  本地按钮: 货币不足则置灰+提示, 不发起请求 (gacha §4)
[扣费校验] ──▶ 服务端权威: 摇号(含保底) (gacha §2 状态机)
    │
    ▼
[揭示演出] 卡背翻转0.3s→光效0.2s→登场定格0.4s (art-bible §8.3)
    │          十连: 逐张 0.15s 错位翻出, 末张 SSR 触发高潮
    │          ★ 一键跳过 / 减弱动效 开关 (reduce motion, §5)
    ▼
[结果结算] SSR 全屏彩带(可关) / 按稀有度双编码定帧
    │
    ▼
[重复处理] 重复→转碎片 (R20/SR50/SSR100) (gacha §3.3)
    │          满星溢出→回收 (R2/SR5/SSR10 ⭐) (gacha §3.5)
    ▼
[仓库回写 + 图鉴解锁 + pity 更新] (SSR 获取 → pity 归零)
    │
    ▼
[回流] 可继续抽 / 去图鉴看新动物 / 去餐厅上岗
```

### 2.4 养成互动（喂食 / 送礼 → 好感 → 上岗）

```
[餐厅/图鉴 点动物] ─▶ [动物详情 Modal]
    │
    ├─ [喂食] 拖拽🍖食材→动物 (或点「喂食」) → +1好感 +10XP / 食材 (cultivation §3.1)
    ├─ [送礼] 点礼物 → +5好感 +50XP (每日同种≤3次, 达上限置灰) (cultivation §3.1)
    │
    ▼
[结算好感/XP] 进度环 + 阶层名(陌生/熟悉/朋友/挚友/家人) + 数值 (三重编码, §5)
    │
    ▼
[里程碑] 20熟悉→槽1 / 50朋友→专属+槽2 / 80挚友→技能(T_serve-5%) / 100家人→idle+3%·碎片+10%
    │
    ▼
[上岗应用] 拖拽动物→工位 → 加成实时生效 (下岗实时增删, 无残留) (cultivation §4)
```

## 3. 交互模型（Interaction Model）

### 3.1 手势映射

| 手势 | 场景 | 行为 |
|---|---|---|
| **点击 Tap** | 所有按钮/动物/卡面 | 主操作；弹跳(1.0→1.12→1.0,120ms)+粒子(art-bible §8.2) |
| **长按 Long-press** | 动物/卡面 | 弹出快捷详情（不进 Modal 全屏，减少跳转） |
| **拖拽 Drag** | 🍖食材→动物（喂食）；动物→工位（上岗）；装饰→槽位 | 拖拽落点命中即触发，落空回弹（无惩罚） |
| **滑动 Swipe** | 抽卡十连结果、图鉴网格、商店列表 | 翻页/横滑；下拉刷新离线收益（可选） |
| **双击** | 不采用 | 避免误触，保持单一主手势（防认知过载） |

### 3.2 每次主动操作的反馈（粒子 + 音效钩子占位）

> 以下为 UX 层反馈契约；**音效钩子以 `[SFX:xxx]` 占位**，由音频（阮和鸣）在 v1.0 接入，本规格不定义音频资产。

| 操作 | 视觉反馈 | 触感(可关) | 音效钩子占位 |
|---|---|---|---|
| 点击按钮 | 弹跳+3–5 颗爱心/星星粒子 | 轻 haptic | `[SFX:ui_tap]` |
| 收菜领取 | 收益「+N⭐」飘字 + 金币雨粒子 | 轻 haptic | `[SFX:collect]` |
| 抽卡揭示 | 翻卡光效 + 稀有度双编码定帧 | SSR 轻柔 haptic(可关) | `[SFX:gacha_reveal]` / `[SFX:gacha_ssr]` |
| 喂食 | 咀嚼 2 次 + 满足表情 + 头顶「+1」 | 满足 haptic(可关) | `[SFX:feed]` |
| 升级完成 | 进度条填满 + 薄荷绿闪光 | 轻 haptic | `[SFX:upgrade]` |
| 里程碑解锁 | 阶层名弹出 + 小礼花 | 轻 haptic | `[SFX:milestone]` |

所有反馈遵循 art-bible §8「慢起、柔动、峰值短促（惊喜只在抽卡）」；reduce motion 开启时粒子/呼吸关闭，保留静态定帧（§5）。

### 3.3 单手可达性（女性向，主操作区偏下）

```
    ┌──────────────────────┐
    │  顶栏(货币/☰/💬)  ← 只读, 非操作 │
    │                        │
    │     内容区(展示)       │
    │      (信息阅读区)      │
    │                        │
    ├──────────────────────┤
    │  ★主操作热区(拇指弧)★ │
    │  [收菜][升级][抽卡]    │ ← 所有主动 CTA 落在屏幕下 1/3
    ├──────┬──────┬────────┤
    │餐厅  │抽卡  │图鉴 商店│ ← 底部 Tab, 拇指自然落点
    └──────┴──────┴────────┘
```
- 原则：阅读信息在上，操作按钮在下；底部 Tab 与主要 CTA 全部位于拇指可达弧（屏幕下 1/3，约 y>800/1334）。
- 升星/送礼等次级操作在 Modal 内，按钮同样贴底。

## 4. 关键界面线框描述（Key Screen Wireframes）

### 4.1 主菜单（Hub / 总览浮层，☰ 唤出；亦为首启着陆）

```
┌─────────────────────────────┐
│  ☰ 主菜单           💬订阅   │  ← 顶栏: ☰返回游戏 / 💬订阅消息
├─────────────────────────────┤
│   👤 头像  昵称  Lv.餐厅 12   │
│   收集进度 ◯ 18/36 (50%)     │  ← 图鉴进度环(集合进度, 情感锚)
│   今日: ⭐+340 💎+0 🍖+120   │
├─────────────────────────────┤
│  ┌──────┐ ┌──────┐          │
│  │ 🏠餐厅 │ │ 🎴抽卡 │  ← 模块入口卡(圆角, 主色底) │
│  └──────┘ └──────┘          │
│  ┌──────┐ ┌──────┐          │
│  │ 📖图鉴 │ │ 🛍商店 │          │
│  └──────┘ └──────┘          │
├─────────────────────────────┤
```

说明：首启时直接落此页，引导玩家「进入餐厅」；游戏内任意模块左上 ☰ 以半屏浮层覆盖，可一键回游戏。

### 4.2 抽卡界面（卡池概率明示 + 保底计数）

```
┌─────────────────────────────┐
│  ☰        🎴抽卡        💬   │
│  ⭐1234  💎56             │  ← 货币 HUD
├─────────────────────────────┤
│  常驻卡池 · 距保底 12/50 抽   │  ← 保底计数(软提示, 见 §6.2 取舍)
│  ┌────────────────────┐     │
│  │  [概率说明 ▼]        │     │  ← 合规固定入口(微信要求明示)
│  │  R 60%  SR 30%  SSR 10% │  │  ← 概率数字 Num 24–28px
│  │  N 0%(不入池) 50抽保底  │  │
│  └────────────────────┘     │
│  当前货币: (●)⭐星券 ( )💎钻石│  ← 货币切换
├─────────────────────────────┤
│  [单抽 100⭐]  [十连 900⭐]   │  ← 主 CTA(暖橘, 偏下)
│  (免费单抽 1/1 今日剩余)      │  ← 每日免费抽(计入保底)
│  新手保底: 再抽 4 次必得 SR   │  ← 前10抽≥1SR 软提示(仅新号)
```

说明：概率与保底为**合规硬展示**（微信平台要求），但视觉以「小字+折叠入口」弱化压力，主视觉留给惊喜（art-bible §8.3）。保底计数用「距保底 X/50」而非倒计时焦虑文案。

### 4.3 餐厅（座位 / 出餐 / 动物访客，核心循环主舞台）

```
┌─────────────────────────────┐

│  │  🐰访客 点单💬 → 🐱出餐  │  │  ← cook→serve 自动演出
│  │  +12⭐ +1🍖 飘字       │  │  ← 收益视觉(+)不依赖音效
│  │  [拖动物→工位上岗]      │  │  ← 拖拽交互(养成联动)
│  └────────────────────┘     │
├─────────────────────────────┤
│  [收菜 +123⭐]  ← 离线/挂机  │  ← 顶部收菜激励(暖橘)
```

### 4.4 图鉴（收集进度 / 家族筛选）

```
┌─────────────────────────────┐
│  ☰        📖图鉴        💬   │
│  收集 ◯ 18/36 (50%)          │  ← 总进度环(情感进度条)
├─────────────────────────────┤
│ [全部][哺乳][鸟][圆团][水族]  │  ← 家族筛选 Tab(对齐 art-bible §4.4.4)
│  R SR SSR 稀有度筛选(形状图标)│  ← 色盲安全筛选(§5)
├─────────────────────────────┤
```

## 5. 可访问性（Accessibility，对齐 art-bible §9 三级）

### 5.1 稀有度色盲安全编码（不只靠颜色）

| 稀有度 | 颜色 | **形状/图标** | 纹理/演出 | 卡面顶部条 |
|---|---|---|---|---|
| N | 灰绿 `#A8C0B0` | **● 圆点** | 无 | 灰绿条 |
| R | 蓝 `#8FB8E0` | **◆ 单钻** | 轻光 | 蓝条 |
| SR | 紫 `#C9A6E8` | **◆◆ 双钻** | 边框微光 | 紫条 |
| SSR | 金 `#F4C95D` | **★ 星冠** | 流光+粒子+彩带 | 金条 |

- 任何稀有度呈现（卡面/图鉴/抽卡结果/筛选）必须**颜色 + 形状图标**双编码；高对比皮肤（Comprehensive 级）额外加纹理。
- 身份色（角色填充，12 配色预设）与稀有度色（卡框条）分属不同 UI 层（tech-prototype ADR-4），不撞色时仍以形状图标兜底。

### 5.2 字号下限与对比度

- **正文下限 18px**（Caption 18–20），数值 Num 24–28px；暖墨置奶白 8:1（AAA）。
- 暖橘 `#FF9E68` 仅用于大色块按钮+描边/图标，**禁用于小字**（对比 2.4:1）。
- 文本支持 1.0–1.5× 缩放（Comprehensive），缩放后布局不破版（线框使用弹性盒，非绝对定位死布局）。

### 5.3 震动反馈开关

- 设置项 `触感反馈 = 开/关`（默认开）。
- 仅「轻柔 haptic」：抽卡 SSR、喂食满足、升级完成、里程碑；非强制、可一键全关。
- 对齐 gacha §6 / cultivation §6「轻柔 haptic（可关）」。

### 5.4 降低动态效果（Reduce Motion）

- 设置项 `减弱动效 = 开/关`（默认关）。
- 开启后：关闭呼吸/眨眼/粒子/抽卡炸裂，保留**静态定帧**（art-bible §8、gacha §6、idle §6、cultivation §6 一致）。
- 抽卡 SSR 全屏彩带可单独关闭（gacha §6），保留定帧不损失信息。

### 5.5 其他

- 命中区 ≥44×44 设计像素（所有可点元素，Standard 级）。
- 收益/状态不依赖颜色单编码（idle §6）：用「+N⭐」飘字 + 图标表达，无声友好。
- 好感度三重编码：进度环 + 数值 + 阶层名（陌生/熟悉/朋友/挚友/家人）（cultivation §6）。

## 6. 反馈与节奏（Feedback & Pacing）

### 6.1 新手前 5 分钟「好玩」曲线（零压力启航）

```
分钟 │ 0–1      1–2      2–3      3–4      4–5
─────┼─────────────────────────────────────────────
事件 │收5只N动物│看自动营业│领首笔星券│免费抽得动物│进图鉴/升1级
─────┼─────────────────────────────────────────────
情绪 │惊喜(礼物)│治愈(被照顾)│胜任(+⭐)│发现(抽卡)│拥有(图鉴+)
曲线 │ ▲ 低门槛  │ 平缓安心   │ ▲小成就  │ ▲峰值惊喜 │ 留存锚定
```
- 前 5 分钟只给**正向小确幸**，无任何失败/倒计时压力（concept §4.2 零失败）。
- 第 3 分钟免费抽命中「前 10 抽≥1 SR」保底，制造首个收集惊喜峰值（Submission+Discovery）。

### 6.2 零惩罚佛系设计

- 无 Game Over / 无死亡 / 订单不扣血（concept §4.2）。
- 满座仅延迟收益，不惩罚；离线超 `T_cap` 不累积但**不扣已得**；回归≥7 日仍照常发礼包（idle §4）。
- 拖拽落空回弹、升星/送礼达上限仅置灰，无任何负反馈弹窗。

### 6.3 推送 / 召回节奏（微信订阅消息占位）

> 微信小游戏无强推送，召回依赖**订阅消息**（用户授权后一次性模板消息）。以下为占位节奏，由运营配置，UX 仅定义入口与文案槽。

| 触发 | 订阅消息模板占位（文案槽） | 频率上限 |
|---|---|---|
| 离线收益成熟 | 「你的小店又赚啦~ 回来收 ⭐ 吧 🐱」 | 每日 ≤1 |
| 免费抽刷新 | 「今日免费抽已到账，新朋友在等你 🎴」 | 每日 ≤1 |
| 保底临近 | 「再抽 X 次必得 SSR 哦 ✨」（仅 pity≥45 软提示） | 仅高 pity |
| 回归礼包 | 「好久不见~ 回来有小礼物 🎁」 | 7 日未登 |

- 入口：所有屏右上 💬 → 订阅管理；首次引导第③步后轻量询问授权（非强制，拒绝也可玩）。
- 文案语气统一「温柔邀请」，绝不用「再不回来就亏了」式焦虑话术（对齐治愈定位）。

## 8. 已标注的 UX 张力（Tensions Flagged）

| # | 张力 | 表现 | 本规格的化解 | 需评审确认 |
|---|---|---|---|---|
| T1 | **合规明示 vs 治愈低压力** | 微信要求抽卡概率/保底强制公示，但明示数字易引发「赌感/焦虑」，伤治愈定位 | 概率以「折叠入口+小字」满足合规硬要求，主视觉弱化数字、强调惊喜；保底用「距保底 X/50」软提示而非倒计时 | 请确认合规文案措辞是否过隐晦（需法务/平台口径） |
| T2 | **保底计数展示 vs 零焦虑** | 展示 `pity` 可能让玩家「计算」而非「享受」 | 仅显示「距保底 X/50」+ 新手「再抽 X 次必得 SR」；不显示 SSR 实时概率曲线 | 是否完全隐藏 pity 数字（仅进度条）？留待评审 |
| T3 | **核心循环三屏内 vs 信息完整** | 餐厅一屏要塞座位/出餐/访客/升级/收菜/广告，易认知过载 | 信息分层：主舞台(座位/出餐) + 底部热区(收菜/升级/广告)；广告为次级折叠 | 需 v1.0 真机验证单屏信息密度 |
| T4 | **IAA 广告入口 vs 无打扰治愈** | 广告加速/双倍若太醒目，像「逼看广告」 | 广告按钮用次级样式、置于底部、明确「可选」；不与主 CTA 抢视觉 | 广告位视觉权重待美术细化 |
| T5 | **单手底部 Tab vs 抽卡全屏演出** | 抽卡 SSR 全屏彩带覆盖底部 Tab，操作中断 | 演出为「反馈」非「操作」，结束后自动回落 Tab；演出期间不阻断（可跳过） | 无冲突，已化解 |
| T6 | **图鉴「未拥有?」期待 vs 收藏焦虑** | 大量🔒可能让玩家觉得「永远集不齐」 | 进度环强调「已得 %」正向，🔒用可爱剪影而非红叉；限定卡单独标记「季节」降低 FOMO | 限定卡展示策略待运营定 |

**主理人特别提示（一致性复查）**：idle-restaurant GDD 顶部注记 `offline_factor` 由 0.25 调为 0.20 系 balance pass v0.2 由主理人直推（design-strategist 子 agent 后端故障），**待 design-strategist 复核签字**。本 UX 规格引用的离线收益默认采纳 0.20，不影响交互结构，但请在评审时一并确认该数值签字。
