## 1. 系统概述与目标

- **定位**：P1「收集」支柱的核心兑现点；玩家获取可上岗的 R/SR/SSR **员工**（动物角色资源）与装饰的**唯一随机来源**（N 不入池，仅免费/任务获取；N = 免费基础员工）。
- **Player Fantasy**：「下一只是什么」的温柔惊喜 —— 用免费积累的星券或付费钻石，把喜欢的小动物**员工**带回家、安排上岗。
- **成功指标**：首抽转化意愿（内测问卷）、图鉴进度周增幅、免费玩家日均抽卡次数中位数、付费率、SSR 保底体验满意度。
- **设计红线**：零失败无惩罚；抽卡是惊喜而非压力；概率全公示（微信平台合规）；不诱导赌博感。

---

## 2. 核心机制

- **货币**：`星券`（免费软货币，放置经营产出）／ `钻石`（付费货币，IAP）。两者**共享同一卡池与同一全局保底计数**。
- **卡池**：单常驻池，稀有度 **R 60% / SR 30% / SSR 10%**，N 概率 = 0%（不入池）。
- **抽卡动作**：
  - 单抽：100 星券 **或** 100 钻石。
  - 十连：900 星券 **或** 900 钻石（9 折），保底 ≥1 SR。
  - 每日免费单抽：1 次/日（服务端 UTC+8 0 点重置），计入保底计数。
- **保底机制**：
  - 全局保底计数器 `pity ∈ [0, 50]`，每次抽卡 +1；获得 SSR 后归零。
  - **硬保底**：`pity ≥ 50` → 本次必出 SSR。
  - **软保底**：`pity ∈ [41, 49]` 时 SSR 概率阶梯递增：
    `SSR_rate(c) = min(1.0, 0.10 + 0.09 × (c − 40))`
    → c=41≈19%、c=45≈55%、c=49≈91%；c=50 → 100%（硬保底）。
  - **新手前 10 抽**（新账号前 10 次抽卡）保底 ≥1 SR。
- **状态机（抽卡）**：
  `idle → 选货币/十连 → 扣费校验(服务端) → 服务端摇号(含保底) → 结果结算 → 重复处理(碎片) → 演出播放 → 仓库回写`
  - **服务端为权威**：摇号、保底计数、碎片、货币余额全部服务端裁决；客户端仅发起请求并播放演出。

## 3. 数值设计

### 3.1 概率表（常驻池）

| 稀有度 | 基础概率 | 备注 |
|---|---|---|
| N | 0% | 不入抽卡池，仅免费/任务/合成获取 |
| R | 60% | — |
| SR | 30% | 十连保底 ≥1；新手前 10 抽保底 ≥1 |
| SSR | 10% | 50 抽硬保底 |

### 3.2 保底计数（全局，跨货币共享）

- `pity` 上限 50；SSR 获取即归零。
- 单抽 / 十连 / 每日免费抽 每次均 +1。

### 3.3 重复（duplicate）→ 碎片

| 重复稀有度 | 获得碎片（该动物） |
|---|---|
| R | 20 |
| SR | 50 |
| SSR | 100 |

### 3.4 升星（star-up）阈值（碎片 → 升星）

| 稀有度 | 升星阈值（碎片/星） | 满星 |
|---|---|---|
| R | 80 | 5 星 |
| SR | 150 | 5 星 |
| SSR | 300 | 5 星 |

### 3.5 碎片溢出回收（防通胀 sink）

- 达到满星（5 星）后，额外同动物碎片按 `1 碎片 = {R:2 / SR:5 / SSR:10} 星券` 回收。
- 该回收为二级 sink，仅用于消纳溢出，不改变抽卡概率/保底。

### 3.6 货币产出对照（来源见对应 GDD）

- `星券`：放置经营在线/离线产出（system-idle-restaurant.md §3.1–3.2）+ 任务 + 每日免费抽。
- `钻石`：IAP 礼包 + 月卡 + 极小任务奖励；**不进入放置经营产出**（防通胀）。

## 4. 边界与异常

- **货币不足**：按钮置灰并提示「星券不足 / 钻石不足」，不发起请求。
- **离线 / 弱网**：抽卡为服务端权威事务；请求超时 → 不扣费、提示重试；结算前断线 → 以服务端最终状态为准，重连后补偿。
- **重复十连边界**：十连保底 SR 与 `pity` 同时触发时，优先满足 `pity`（若该次本为 SSR，则 SR 保底顺延至同十连其他位）。
- **仓库 / 图鉴**：动物按 id 去重（图鉴制），无「背包满」概念；碎片累加。
- **概率公示合规**：UI 固定入口展示 R60/SR30/SSR10 与 50 抽保底，与服务端一致。
- **时区 / 每日免费**：以服务端 UTC+8 0 点结算，防本地改时区刷免费抽。

---

## 5. 反作弊与安全

- **服务端权威**：摇号、保底、`pity`、碎片、余额全部服务端；客户端无法伪造结果。
- **货币不可本地修改**：星券/钻石余额以服务端为准；本地仅缓存展示。
- **请求幂等**：`requestId` 去重，防重复提交 / 重放刷抽。
- **防时钟回拨**：免费抽与离线收益均以服务端时间戳，本地时钟不影响保底与免费次数。
- **越狱 / 篡改**：关键校验放服务端；客户端仅做体验与演出。

---

## 6. 可访问性

- **稀有度双编码**（art-bible §7.2）：颜色 + 角标形状（N 圆点 / R 单钻 / SR 双钻 / SSR 星冠）+ 纹理，色盲安全。
- **文字**：正文 ≥18px（art-bible 基准）；概率数字用 Num 层级 24–28px。
- **动效**：抽卡演出支持「一键跳过 / 减弱动效」（reduce motion）；SSR 全屏彩带可关，保留静态定帧。
- **触感**：SSR 抽出时轻柔 haptic（可关）；非强制。
- **高对比 UI 皮肤**：稀有度额外纹理编码（Comprehensive 级，art-bible §9）。
- **命中区**：核心按钮 ≥44×44 设计像素。

---

## 7. 依赖与接口

- **依赖**：账号/存档（微信开放数据，服务端）；经济系统（星券/钻石余额）；图鉴系统（动物定义、id、稀有度）；养成系统（升星→碎片→动物等级上限）；放置经营（星券产出来源；**抽卡产出的动物即「员工」候选，于 system-idle-restaurant.md 上岗到 厨师/服务员/接待 三岗**）。
- **提供事件**：`onGachaResult{animalId, rarity, isDuplicate, shardGain}` → 订阅方：图鉴、养成、任务。
- **引擎接口**：卡面立绘运行期程序化拼装（base-parts atlas）；抽卡演出特效（SSR 全屏彩带预载依据 art-bible A.6.3）。
