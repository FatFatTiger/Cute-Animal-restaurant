# 《可爱小动物餐厅》Phase 1 游戏概念文档

> 版本：v0.1.2（接手修订 · 已 design-strategist 复核签字）｜负责人：design-strategist（文策渊）｜状态：已评审落盘｜复核：文策渊 · 2026-07-28 · 结论：通过

## 0. 文档定位与依据

本项目为微信小游戏「收集养成 + 模拟经营放置」原创 IP 产品，目标人群女性向治愈用户。本文档为 Phase 1 概念孵化产出，把模糊点子结构化为可评审、可实现的基线。

**核心市场依据（来自《微信小程序移植机会扫描》）：**
- 大盘 MAU >5 亿；模拟经营品类年增 >200%、二合 >70%；放置/卡牌为蓝海（历史注册 3–5 亿，有效用户 1 亿+）。
- 「她力量」：女性付费用户年增 20%、ARPPU +10%，为项目核心红利窗口。
- 平台顺风：2026 新游 IAP 首发 5000 万内不分成、iOS 支付即将开放。
- 技术硬约束：主包 4MB 上限（Cocos 运行时内置微信客户端不占包）；JS/TS 沙箱无 DOM；实时联机成本极高 → 优先纯单人/异步。
- 品类契合度：「收集养成 + 战棋」移植评分综合 86 分（Tier 1）；本项目取其"收集+养成"内核，去掉战棋硬核，改"放置经营"软核，更契合女性向治愈。

**设计红线（全程遵守）：** 杜绝主导策略、经济失衡、认知过载、支柱漂移。

**主理人一致性裁定（v0.1.1）**：稀有度统一为 4 档 N/R/SR/SSR，N=免费基础动物（与美术圣经对齐）；抽卡付费池为 R/SR/SSR（概率 R60/SR30/SSR10）。抽卡基准 SSR 10% + 50 抽保底获确认。落盘路径 design/gdd/concept-doc.md。

## 1. 游戏支柱（Game Pillars，动词优先）

采用动词优先法，三条支柱互为输入/输出构成闭环、不漂移。

| # | 支柱（动词） | 一句说明（为什么做） |
|---|---|---|
| P1 | **收集** | 让玩家通过抽卡/任务持续获得原创小动物卡片与餐厅装饰，制造"下一只是什么"的期待与拥有感，驱动日活与付费。 |
| P2 | **经营** | 以放置式自动营业让玩家以极低操作看到小动物们自己干活、产出资源，提供"被照顾"而非"在打工"的治愈反馈。 |
| P3 | **养成** | 通过喂食/升级/装扮把每只动物与餐厅养成为"我的"情感资产，制造沉没成本与审美表达，支撑长线留存。 |

支柱闭环：收集（获取动物/装饰）→ 经营（动物自动产出）→ 养成（消耗产出变强变美）→ 更强经营 → 再收集。

## 2. MDA 框架分析

### 2.1 Mechanics（核心机制清单）
1. **抽卡系统**：原创卡池（R/SR/SSR），软保底；单抽/十连；免费「星券」+ 付费「钻石」。
2. **放置经营**：员工（动物）上岗自动服务带菜需求的顾客、产出星券+食材；无需实时操作。
3. **离线收益**：离线期间按比例累积收益，上线领取（idle 内核）。
4. **餐厅布局/扩张**：解锁区域、拖拽放置动物工位与家具；工位数量决定产能上限。
5. **养成系统**：喂食（消耗食材升好感/等级）、动物技能解锁、星级突破。
6. **装扮系统**：主题皮肤、家具、背景，纯个性化表达（不影响数值或弱影响）。
7. **图鉴**：收集完成度可视化，作为终局目标与情感进度条。
8. **任务/成就**：日常、周常、新手引导、收集成就。
9. **体力/时间闸**：轻量时间闸门（非惩罚性），控制产出节奏、为广告/付费留口。
10. **分享/异步（后做）**：生成餐厅海报、动物卡片分享图；异步排行榜/好友助力。

### 2.2 Dynamics（机制涌现的玩法）
- **收集驱动留存**：图鉴空缺 + 抽卡随机性 → 玩家为"集齐"持续登录与付费。
- **挂机零压力**：放置+离线收益 → 碎片化 1–5 分钟即点即玩，弱留存压力，契合小程序会话特征（日均 60 分钟但极碎片化）。
- **经营×收集耦合**：扩张区域需更多动物工位 → 经营需求反推收集，避免单一系统枯竭。
- **情感沉没成本**：好感度/养成让玩家对特定动物产生依恋，"我的小猫" > "一张卡"。
- **收菜节奏**：离线收益 + 体力闸制造"回来收菜"日活钩子，提升次留/7 留。
- **炫耀需求（后做）**：装扮差异化 + 分享图 → 内容裂变，替代强制社交。

### 2.3 Aesthetics（LeBlanc 八维取舍）
重点落在**女性向治愈 / 探索 / 发现**，刻意压低 Challenge 与 Fellowship。

| 趣味维度 | 取舍 | 设计落点 |
|---|---|---|
| **Discovery 探索/发现** | ★重点 | 图鉴解锁、隐藏动物、随机事件掉落、季节限定卡 |
| **Sensation 感官** | ★重点 | 马卡龙配色、软萌音效、呼吸/眨眼程序化 idle 动画 |
| **Expression 表达** | ★重点 | 餐厅自由布局、主题装扮、个性化招牌 |
| **Submission 沉溺/禅意** | ★重点 | 放置挂机、无失败无惩罚、慢节奏治愈 |
| **Fantasy 幻想** | ◐中 | 经营童话萌宠餐厅的代入感 |
| **Narrative 叙事** | ◐中（后做） | 动物日记/小剧情轻量承载 |
| **Fellowship 社交** | ○后做 | 异步排行榜、好友助力（非实时） |
| **Challenge 挑战** | ○不作重点 | 刻意弱化，避免压力伤害治愈定位 |

美学定位一句话：**"低操作、高反馈、慢节奏、可被拥有"的治愈系收集经营。**

## 3. 核心循环与元循环（文字流程图）

### 3.1 Core Loop（单次游玩，单局 ≤5 分钟）
```
[登录] → [收菜：领取离线/挂机收益]
   → [巡查：检查员工三岗 / 顾客菜需求（轻点交互）]
   → [产出：自动营业服务顾客 → 星券 + 食材 + 好感度]
   → [消耗：喂食升级员工 / 扩张工位 / 解锁菜品（星券+食材）（消耗资源）]
   → [收集：攒货币 → 抽卡得新动物员工或装饰]
   → [装扮：布置餐厅 / 解锁主题]
   → [离线下线：收益继续累积]
   └──────────────┘ (回到登录，收益已增长)
```
核心动词链：**收菜 → 服务顾客 → 养成/收集/解锁菜品 → 变强变美 → 下线 → 收更多**。

### 3.2 Meta Loop（长线留存，周/月尺度）
```
[新手引导：5 只基础动物（N 档）+ 1 区域]
   → [日常任务 + 离线收益 → 攒星券/钻石]
   → [抽卡：图鉴进度 X%]
   → [解锁新菜品 → 可服务更多顾客 → 经营产能↑]
   → [养成高阶动物 → 单位产出↑]
   → [周/月活动：限定卡/赛季 → 回流钩子]
   → [终局目标：全图鉴 + 满级餐厅 + 完美装扮]
   └──────────────┘ (赛季重置部分产出，循环续命)
```
Meta 目标锚：图鉴完成度（情感）+ 餐厅等级（成就）+ 限定收集（稀缺）。

## 4. 玩家心理学锚点（SDT 三需求 + 女性向治愈落点）

### 4.1 自我决定论三需求映射
| 需求 | 满足方式 | 具体机制 |
|---|---|---|
| **自主 Autonomy** | 玩家按自己节奏玩，无强制操作 | 自由排布动物工位/餐厅布局；放置玩法无 DPS 压力；装扮自定义 |
| **胜任 Competence** | 清晰可见的"变好"反馈，平缓曲线 | 升级/图鉴%/餐厅等级可视化成长；任务难度低、零失败；成就即时庆祝 |
| **关联 Relatedness** | 情感投射 + 轻社交纽带 | 对原创动物的"我的孩子"投射；动物日记小剧情；异步好友/排行榜（后做） |

### 4.2 女性向治愈诉求的具体设计落点
- **零失败 / 无惩罚**：没有 Game Over、没有死亡、订单不会扣血，治愈核心不可妥协。
- **碎片化友好**：单局 ≤5 分钟，挂机也能成长，通勤/睡前随手点。
- **感官安抚**：低饱和奶油色系 + 圆润幼态体型 + 软萌音效 + 程序化微动画。
- **情感资产**：收集+养成把"卡牌"变成"我的宠物"，制造情感满足与沉没成本。
- **审美表达**：装扮系统满足"布置属于自己的小店"的掌控与审美愉悦。
- **每日小确幸**：签到/收菜的仪式感，给平淡日常一个温柔锚点。

## 5. 范围分层（MVP / v1.0 / 长线）

优先级：P0=阻塞核心闭环必做；P1=上线体验完整度；P2=增益/后做。

### 5.1 MVP（最小可玩，验证核心循环：抽卡→经营→养成）
目标：2–4 周可玩切片，验证"收菜—产出—养成/收集"闭环留存与付费意向。
- **P0**：抽卡（基础软保底）、放置经营（自动产出）、动物养成（喂食/升级/好感）、餐厅基础布局（单区域）、离线收益、图鉴、核心 HUD/主菜单、账号存档（微信开放数据）。
- **P1**：新手引导（5 只基础动物 N 档）、日常任务、基础成就、基础音效、分享图生成。
- **P2**：装扮装饰（极简占位）、十连。
- **MVP 验收**：次留 ≥30%、核心闭环 7 日仍活跃占比、首抽转化意愿（内测问卷）。

### 5.2 v1.0（上线版本）
- **P0**：完整抽卡（概率公示 + 十连 + 50 抽保底 SSR）、体力/时间闸、餐厅多区域扩张、活动系统框架、IAP 接入（首充/月卡/钻石）、IAA 激励视频接入、签到、分包资源加载。
- **P1**：完整装扮系统、动物技能/工位差异化、数值平衡、美术主题皮肤、轻剧情日记、分享裂变（海报/卡片图）。
- **P2**：异步排行榜、好友助力、新手 7 日留存活动。

### 5.3 长线（运营期）
- **P0**：赛季/限定卡、新餐厅主题、数值通胀管控（升华/转生）、运营活动节奏表。
- **P1**：异步社交、UGC 装饰、跨店访问/点赞。
- **P2**：原创 IP 联动（无现存 IP）、矩阵小游戏互通、周边衍生探索。

## 6. 视觉锚点初稿（给美术 / art-director）

> 本节为概念层方向，正式视觉身份由 art-director 美术圣经细化，下面关键词需与之对齐。

**方向关键词（5 个）：**
1. **配色**：低饱和马卡龙/奶油色系（奶白、薄荷绿、樱粉、鹅黄），高亮度柔光，无强对比。
2. **体型**：圆润 Q 版、2–3 头身、大头小身、幼态可爱（幼态持续 = 治愈）。
3. **材质**：扁平 + 轻软阴影/微厚涂；优先**程序化矢量+渐变**，避免逐张高精贴图以压包。
4. **情绪**：温暖、松弛、无攻击性；"想抱一抱"的柔软感。
5. **动态**：轻微呼吸/眨眼/摇摆的**程序化 idle 动画**（骨骼/参数驱动，不靠逐帧）。

**参考风格描述：**
- 治愈 2D 手绘：《动物餐厅》(Animal Restaurant)、《猫咪和汤》(Neko Atsume 系)。
- 极简禅意：《旅かえる》(旅行青蛙) 的留白与柔和。
- 程序化方向：《Florence》的简洁色块 + 《Alto's Odyssey》的柔和渐变天空。
- **卡牌表现**：动物采用"身体部件 + 配色参数"程序化拼装（头/身/耳/尾/配色预设），用极少基础贴图组合出大量原创形象，直接缓解 4MB 包体压力（与美术圣经的程序化资产规格对齐）。

## 7. 初步商业化钩子

### 7.1 卡牌获取节奏（保底/概率）
- **双货币**：免费「星券」（经营/任务产出）+ 付费「钻石」（IAP）。
- **稀有度（4 档，主理人一致性裁定 v0.1.1 对齐美术圣经）**：N = 免费基础动物（新手 5 只 + 任务/合成产出，不入抽卡池）；R / SR / SSR = 抽卡付费池。
- **抽卡池概率（基础池）**：R 60% / SR 30% / SSR 10%（原创三档，N 不在付费池内）。
- **软保底**：40 抽后 SSR 概率阶梯递增，**50 抽必出 SSR**；新手前 10 抽保底 1 张 SR。
- **十连**：9 折 + 保底 ≥1 张 SR。
- **免费抽**：每日 1 次免费单抽（签到/回归），维持日活。

### 7.2 广告植入点（IAA 激励视频，非强制）
- **加速**：动物产出/烹饪 ×2 速度（看广告）。
- **双倍产出**：离线收益/订单奖励翻倍（看广告）。
- **抢救**：订单即将结束，看广告延长/免罚（治愈向仅"补救"不"惩罚"）。
- **免费抽**：看广告得 1 次单抽。
- **体力恢复**：看广告回满体力闸。

### 7.3 首充 / 月卡 / 基金建议
- **首充 ¥6**：送 1 只限定 SR + 30 天每日钻石 + 专属装饰（极低门槛转化锚）。
- **月卡 ¥30/月**：每日领钻石+星券+加速券（性价比锚，拉 ARPPU）。
- **成长基金**（一次性）：按图鉴%/餐厅等级里程碑返还钻石，长线付费引导。
- **餐厅通行证**（P1）：免费+付费双轨 BattlePass 式，绑定装扮与限定。

## 8. 已知风险与缓解

| 风险 | 说明 | 缓解策略 |
|---|---|---|
| **4MB 主包硬限** | 卡牌/场景资源多，超包无法上传 | 美术程序化（部件拼装+参数化配色）；音频短循环 ogg 压缩；Cocos 不占包；分包 16MB+ 远程按需加载，首屏极简 |
| **纯单人缺裂变** | 实时联机贵，强社交不可行 | 微信天然内容分享（餐厅海报/动物卡片图）；异步排行/助力后做；治愈"可爱分享"替代强制社交 |
| **女性向竞争激烈** | 同类治愈产品多 | 差异化原创 IP + "零失败治愈"细分定位；美术/音效打磨；社区内容运营（晒店/晒宠） |
| **养成数值通胀** | 长线数值膨胀摧毁经济 | 双货币隔离（免费/付费）；稀缺货币硬控；SSR 总量与产出受控；升华/转生软上限；图鉴完成度作终局而非无限数值；赛季重置部分产出 |

**附加红线自检**：当前设计无单一主导策略（收集/经营/养成相互制衡）；经济双货币隔离防失衡；单局 ≤5 分钟防认知过载；三支柱闭环防漂移。
